# Site de Casamento

MVP funcional com Next.js, React, TailwindCSS, Supabase e Mercado Pago Checkout Pro.

## Comandos

```powershell
cd C:\site_casamento
npm install
Copy-Item .env.example .env.local
npm run dev
```

Depois abra `http://localhost:3000`.

O guia completo esta em `docs\PASSO_A_PASSO.md`.
